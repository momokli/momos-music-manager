What it does

A local-first library hub that keeps your Spotify, SoundCloud and file collection in sync — and your DJ software speaking the same language.

🔄

Library sync

Sync playlists and tracks from Spotify and SoundCloud into one local library. Subscribe to playlists, track changes, and keep everything in a single SQLite database.

🎵

Harmonic matching

BPM & key detection with Camelot-wheel compatibility. Compare keys between Traktor and Spotify, discover harmonic matches, and build sets that stay in key.

🏷️

Tag organization

Free-form tags with categories and parent relations, plus AI-assisted auto-categorization powered by a local embedding model (all-MiniLM-L6-v2) that runs entirely on your machine — no cloud, no API keys. Tags map to playlists by name, and get written into ID3 comments for use in any DJ software.

🎧

Traktor integration

Import your collection.nml, run consistency checks, and write BPM/key/comment metadata back so Traktor Smart Lists just work.

🖥️

Web UI, locally

A fast, dark-themed single-page app served by the app itself — no Node, no Python, no separate dev server. One binary, one port, localhost:3000.

🍎

Native macOS app

Menu-bar app with a universal DMG installer. Starts on login, runs in the background, re-opens your browser dashboard. Ad-hoc signed — details in the download section.

Verify your download (SHA256)

Every artifact ships with a .sha256 file and is listed in the aggregate SHA256SUMS. Compare the hash of the file you downloaded with the published checksum:

macOS

shasum -a 256 Momo-s-Music-Manager-latest.dmg

…then compare with the linked .sha256 file.

Linux

curl -fLO https://github.com/momokli/momos-music-manager/releases/download/latest-main/momos-music-manager-latest-linux-x64.tar.gz.sha256
sha256sum -c momos-music-manager-latest-linux-x64.tar.gz.sha256

Windows (PowerShell)

Get-FileHash .\momos-music-manager-latest-windows-x64.zip -Algorithm SHA256

…then compare with the linked .sha256 file.

🍎 macOS — first launch

The DMG is ad-hoc signed and not notarized, so Gatekeeper may block it. Expected for a hobby project without an Apple Developer account:

  1. Download and open the DMG.
  2. Drag momos music manager into Applications.
  3. First start: right-click the app → Open → Open.

The app runs in the menu bar (no dock icon) and opens your browser at localhost:3000. Notarization is planned — roadmap M4.

🪟 Windows — SmartScreen

Builds are unsigned, so SmartScreen/Defender may show “Windows protected your PC”. Click More info → Run anyway. The zip contains momos-music-manager.exe, README.md, VERSION and RUN.txt — no installer. Code signing is planned — roadmap M3.

🐧 Linux — portable archive

Portable tar.gz with the binary, INSTALL.txt and a systemd unit (deploy/momos-music-manager.service) for headless server mode. No GUI — the app serves its web UI on localhost:3000. AppImage/Flatpak is planned — roadmap M5.
