What it does

A local-first library hub that keeps your Spotify, SoundCloud and file collection in sync — and your DJ software speaking the same language.

🔄

Library sync

Sync playlists and tracks from Spotify and SoundCloud into one local library. Subscribe to playlists, track changes, and keep everything in a single SQLite database.

🎵

Harmonic matching

BPM & key detection with Camelot-wheel compatibility. Compare keys between Traktor and Spotify, discover harmonic matches, and build sets that stay in key.

🏷️

Tag organization

Free-form tags with categories, parent relations and AI-assisted auto-categorization. Tags map to playlists by name, and get written into ID3 comments for use in any DJ software.

🎧

Traktor integration

Import your collection.nml, run consistency checks, and write BPM/key/comment metadata back so Traktor Smart Lists just work.

🖥️

Web UI, locally

A fast, dark-themed single-page app served by the app itself — no Node, no Python, no separate dev server. One binary, one port, localhost:3000.

🍎

Native macOS app

Menu-bar app with a universal DMG installer. Starts on login, runs in the background, re-opens your browser dashboard. Ad-hoc signed — details in the download section.

⚠️ First launch on macOS

The DMG is ad-hoc signed and not notarized, so Gatekeeper may block it. Don't worry — this is expected for a hobby project without an Apple Developer account:

  1. Download and open the DMG.
  2. Drag Momo's Music Manager into Applications.
  3. First start: right-click the app → Open → Open.

The app runs in the menu bar (no dock icon) and opens your browser at localhost:3000.
